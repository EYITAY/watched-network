# The Watched Network

Algorithmic artwork (p5.js) based on the research project
[Monitored Collusion in LLM Auctions](https://github.com/EYITAY/Monitored-Collusion-in-LLM-Auctions).

Three agents, one observing eye. Conceptual art, not raw game logs.

Single static page: `index.html`. Deploy as a static site (e.g. Vercel).
